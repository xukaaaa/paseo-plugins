# paseo-tps

Hiển thị tốc độ sinh văn bản ước lượng của Pi trong lúc stream và dưới câu trả lời đã hoàn tất.

## Cài đặt

Cần Paseo ≥0.10.3; daemon cần Git, Node.js và npm.

Dán source vào **Settings → Plugins**, bật **Enable plugins** và bấm **Install plugin**:

```text
github:xukaaaa/paseo-plugins:plugins/paseo-tps
```

Hoặc chạy:

```bash
paseo plugin install github:xukaaaa/paseo-plugins:plugins/paseo-tps
```

Bắt đầu một lượt Pi mới để đo TPS.
